# R2 · Cloudflare Tunnel 公网穿透

## 目标
把本地（Debian 13 的 Docker 内）的 API 服务暴露到公网，学员/家长可访问。

## 前置
- Cloudflare 账号，zone `frc9597.com` 已在 Cloudflare DNS
- API token 含 **Tunnel + DNS** 权限
- R1 已完成（本地 health 200）

## 关键概念（学习要点）
1. **为什么数据库不能直接穿透**：PostgreSQL 只说 5432 协议，浏览器只会 HTTP；必须由 API 桥转一层
2. **Quick Tunnel vs 命名 Tunnel**：临时隧道有 200 并发限制；命名隧道无限流、域名固定（用命名隧道）
3. **token 式远程管理**：cloudflared 只管连接，配置在 Cloudflare 面板，重启即自动恢复

## 执行方式
- executor: human（全手动，见 `R2.plan.yaml`）
- 测试：`.ai/prd/TESTPLAN.md` → GATE A（A-4~A-5、M-A1~M-A3）

## 验收注意
- 公网设备**必须用手机流量/另一网络**，不能与 Debian 同局域网，否则测的是内网
- Debian 离线 → 公网不可达，属预期行为（不视为失败）
