# R1 · 本地部署栈

## 目标
亲手用 Docker 把 Node.js API + PostgreSQL 跑起来，并理解 Node 项目每个文件的含义。

## 涉及文件
- `compose.yml`（编排 postgres + api）
- `Dockerfile` / `.dockerignore`
- `package.json` / `tsconfig.json`
- `src/index.ts`（服务器入口）、`src/db.ts`（PG 连接）
- `.env.example`（配置模板）

## 执行方式
- executor: human（全手动，见 `R1.plan.yaml`）
- 教学手册：`frc9597-backend/docs/lesson-R1.md`
- 测试：`.ai/prd/TESTPLAN.md` → GATE A（A-1~A-3）

## 学习要点
1. Node 项目 = 文件夹 + `package.json`（清单）+ 源码
2. `npm install` 拉依赖；`npm run dev` 起开发服务
3. Docker 容器 ≈ 独立小电脑；`compose.yml` 一键编排多容器
4. `/api/health` = 后端自检接口（服务 + 数据库都活着才返回 up）
