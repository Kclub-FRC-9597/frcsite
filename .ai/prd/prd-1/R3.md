# R3 · PostgreSQL 基础设施

## 目标
打通"API 代码 → PostgreSQL"的连接与建库机制，并建立**按域分 schema** 的规范（为未来扩展到整个站点预留）。

## 学习要点
1. **连接字符串**：`postgres://user:pass@host:port/db`，代码里从环境变量读
2. **连接池（Pool）**：复用连接，避免每个请求新建
3. **迁移（migration）**：把"建表"变成可重复执行的版本化脚本，记录已执行版本
4. **schema 命名空间**：`CREATE SCHEMA inspire`，每个业务域独立，互不污染；未来 prescout/scouting/site 并列

## 执行方式
- executor: human（全手动，见 `R3.plan.yaml`）
- 测试：`.ai/prd/TESTPLAN.md` → GATE B（B-1~B-4、M-B1）

## 涉及文件
- `src/db.ts`（Pool + 查询封装）
- `migrations/001_init.sql`（基础：schema 命名空间 + 迁移表）
- `package.json` scripts（migrate）
