# R7 · 统一 apiFetch + 401/403 弹窗

## 学习要点
1. **fetch 封装**：一处处理所有请求的鉴权头 + 错误
2. **401 处理**：token 缺失/失效 → 弹窗"请先登录" + [去登录]按钮
3. **403 处理**：角色无权限 → 弹窗"当前账号无权限"
4. **静态 vs 数据**：静态资源公开；只有拉数据库的功能才鉴权

## 验收
- 未登录打开需要数据的页面/按钮 → 弹窗提示登录
- 学生账号点教练功能 → 弹窗提示无权限
- 登录后正常访问数据
- 静态页（HTML/CSS/JS）无需登录可浏览
