# R3 · 鉴权中间件

## 学习要点
1. **无状态签名 token**：内容（username+role+exp）+ 签名，服务端验签即得身份，**不查库**
2. **中间件**：请求进入 handler 前的"关卡"，统一校验
3. **401 vs 403**：401=未登录/token 无效；403=登录了但角色没权限
4. **数据隔离**：从 token 读 username，学生提交强制绑定自己身份

## 验收
- 登录成功 → 返回 { username, role, token }
- 无 token / 错误 token / 过期 token → 401
- 角色不符（学生调 import）→ 403
- 鉴权过程不触发任何 D1 查询（可检查 meta 或日志）
