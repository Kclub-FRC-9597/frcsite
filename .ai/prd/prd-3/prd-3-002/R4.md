# R4 · 只读接口 /api/snapshot

## 学习要点
1. **GET handler**：接收请求 → 验签 → 查库 → 返回 JSON
2. **按角色裁剪**：学员只返回自己的成绩/公开字段，教练返回全部（数据隔离）
3. **缓存头**：`Cache-Control: public, max-age=60` → CF 边缘缓存，命中不触发 Worker/D1
4. **索引**：聚合查询走 mock_scores(mock_id, student_id) 索引，省 rows_read

## 验收
- 未登录 → 401
- 学员 → 只含自己数据
- 教练 → 全量数据
- 响应含 Cache-Control 头
- 第二次请求（缓存窗口内）不触发 Worker/D1
