# R5 · 写接口 /api/import

## 学习要点
1. **POST 与请求体**：从请求 body 读 JSON
2. **事务（transaction）**：一组写要么全成功要么全回滚
3. **upsert / 幂等**：`INSERT ... ON CONFLICT(id) DO UPDATE`，同一数据导入多次结果一致
4. **两种模式**：merge（只新增/更新，不删）与 replace（清空后导入）
5. **scores 拆表写入**：import 时把 scores 拆成 mock_scores 多行写入（而非整坨 JSON）

## 验收
- 无/错 token → 401；学生 → 403
- merge 重复导入 → 计数不翻倍、无脏数据
- replace 导入 → 与本地一致、无残留
- mock_scores 按行写入成功
