# R6 · 学生提交 /api/submit

## 学习要点
1. **数据隔离**：服务端从 token 读身份，不信任客户端传的 username
2. **增量写**：一次提交 = 写 mock_scores 一行，不是全量 JSON（超量无忧的关键）
3. **幂等**：同 mock+task+round 重复提交 → upsert 更新，不重复
4. **权限**：学生只能提交自己的成绩（403 拒绝越权）

## 验收
- 无/错 token → 401；教练 → 403
- 学生提交成功 → mock_scores 新增/更新一行
- 尝试提交他人 username → 403/400 拒绝
- 重复提交同一 round → 更新不新增
- 提交后 snapshot（学生视角）能读到
