# prd-3-001 · 数据与契约

## 本子组目标
1. 把 inspire 现状前端数据模型（students/classes/enrollments/tasks/trainings/mockCompetitions/scores/...）映射成 D1 关系表
2. 定义稳定的 API 契约文档（`.ai/prd/prd-3/docs/api-contract.md`），前端（R7）与后端（R4~R6）**只通过契约耦合**

## 数据模型对照（现状 → D1）
| 前端 Shared.data | D1 表 |
|------------------|--------|
| students | students |
| classes | classes |
| enrollments | enrollments |
| tasks | tasks |
| trainings | trainings + training_students + training_tasks |
| training.mockCompetitions | mocks（tasks/comments/schedule 留 JSON 列）|
| mock.scores | **mock_scores（独立表，增量写）** |
| currentTrainingId | meta.is_current |

> 关键设计：scores 从"嵌在 mocks 的 JSON"拆成独立表 mock_scores，一次提交=写一行，避免整坨 JSON 全量重写导致超量。
