# R2 · API 契约

## 契约内容（详见 `.ai/prd/prd-3/docs/api-contract.md`）
- `POST /api/auth/login`：公开；返回 { username, role, token }
- `GET /api/snapshot`：**需登录**；按角色裁剪数据（学员看自己/公开字段，教练看全部）
- `POST /api/import`：教练/管理员；merge | replace；按 id upsert 幂等
- `POST /api/submit`：学生；**只能写自己 username** 的成绩；增量写单行
- 统一错误码：`400` 参数错、`401` 未登录/token 失效、`403` 角色无权限、`500` 服务错

## 访问控制矩阵（本 PRD 核心）
| API | 公开 | admin/coach | student |
|-----|------|-------------|---------|
| POST /api/auth/login | ✅ | — | — |
| GET /api/snapshot | ❌ | ✅ 全量 | ✅ 仅自己/公开字段 |
| POST /api/import | ❌ | ✅ | ❌ |
| POST /api/submit | ❌ | ❌ | ✅ 仅自己 username |
| 静态资源 /assets | ✅ | ✅ | ✅ |

## 学习要点
1. REST = HTTP 方法 + URL + 状态码的约定
2. 契约 = 前后端之间的"接口合同"，先定好再各做各的
3. 错误码语义：401 是"未认证"、403 是"认证了但没权限"、4xx 客户端问题、5xx 服务端问题
