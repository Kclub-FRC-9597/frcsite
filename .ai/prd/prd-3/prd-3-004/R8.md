# R8 · D1 索引 + 缓存策略

## 学习要点
1. **索引**：`WHERE mock_id=? AND student_id=?` 走索引避免全表扫描
2. **rows_read 计量**：D1 按扫描行数计费，索引直接降成本
3. **边缘缓存**：Cache-Control 让 CF 边缘直接回响应，Worker/D1 都不触发
4. **免费档余量**：验证后确认用量占比（目标 <5%）

## 验收
- 索引已建（\indexes 或迁移可见）
- 相同查询加索引前后 rows_read 对比明显下降
- snapshot 响应含 Cache-Control 头
- 缓存窗口内第二次请求不触发 Worker/D1（看 CF 边缘命中日志）
