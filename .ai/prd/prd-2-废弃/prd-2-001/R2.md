# R2 · API 契约

## 契约内容（详见 `.ai/prd/prd-2/docs/api-contract.md`）
- `GET /api/snapshot`：公开；返回全部数据（students/classes/enrollments/tasks/trainings/mocks/...）
- `POST /api/import`：需 `Authorization: Bearer <token>`；请求体为 makexScoreData 结构 + `mode`（merge | replace）；按 id upsert 幂等
- 统一错误码：`400`（参数错）、`401`（未授权）、`500`（服务错）

## 学习要点
1. REST = HTTP 方法 + URL + 状态码的约定
2. 契约 = 前后端之间的"接口合同"，先定好再各做各的
3. 错误码语义：4xx 是客户端问题，5xx 是服务端问题

## 执行方式
- executor: human（编写契约 + 评审均手动，AI 提供草案与讲解）
- 测试：`.ai/prd/TESTPLAN.md` → GATE C 契约核对
