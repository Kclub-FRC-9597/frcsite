# prd-2-001 · 数据与契约

## 本子组目标
1. 把 inspire 现状前端数据模型（students/classes/enrollments/tasks/trainings/mockCompetitions/scores/...）映射成 PostgreSQL 结构
2. 定义稳定的 API 契约文档（`.ai/prd/prd-2/docs/api-contract.md`），前端（R6）与后端（R4/R5）**只通过契约耦合**，可并行

## 数据模型对照（现状 → 数据库）
| 前端 Shared.data | 数据库 |
|------------------|--------|
| students | inspire.students |
| classes | inspire.classes |
| enrollments | inspire.enrollments |
| tasks | inspire.tasks |
| trainings | inspire.trainings + training_students + training_tasks |
| training.mockCompetitions | inspire.mocks（tasks/scores/comments/schedule 用 JSONB） |
| currentTrainingId | inspire.meta.is_current |
