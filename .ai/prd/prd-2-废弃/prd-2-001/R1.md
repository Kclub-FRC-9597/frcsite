# R1 · Inspire 数据库 schema

## 表清单（schema: inspire）
1. `students(id, name, created_at, updated_at)`
2. `classes(id, name, created_at, updated_at)`
3. `enrollments(id, student_id, class_id, status, created_at, updated_at)` + 索引
4. `tasks(id, name UNIQUE, type, max_score, created_at, updated_at)`
5. `trainings(id, name, date, is_current, created_at, updated_at)`
6. `training_students(training_id, student_id)` PK 组合
7. `training_tasks(training_id, task_id, rounds)` PK 组合
8. `mocks(id, training_id, name, date, competition_type, round_type, group, participant_count, tasks_json jsonb, scores_json jsonb, comments_json jsonb, schedule_json jsonb, created_at, updated_at)` + 索引
9. `meta(key, value)`（schema_version / last_import_at / is_current）

## 学习要点
- 实体表规范化（id 稳定）vs JSONB 列（贴合前端嵌套成绩结构）
- `rankings` 是派生数据 → **不落库**，前端 Analysis 现算，避免双端不一致
- `updated_at` 为未来增量同步/冲突检测预留
