# R3 · 鉴权中间件

## 学习要点
1. **HTTP 头**：`Authorization: Bearer <token>` 是携带凭据的标准方式
2. **中间件（middleware）**：请求进入 handler 前的"关卡"，可统一做校验
3. **读写分离**：读公开、写需 token —— 学员/家长只能读，教练才能写

## 验收
- `curl -X POST .../api/import`（无 token）→ 401
- `curl .../api/snapshot`（无 token）→ 200
- 错误 token → 401
