# R4 · 集训达标展示

## 目标

在集训详情页把用时目标落地为可视化：达标徽章 + 概览汇总 + 学员覆盖。

## 交互

1. **目标首行**：概览表格顶部（最佳成绩之前）新增「🎯 目标」行：任务列显示该任务的目标用时区间（如 ≤12s / 8~12s）；每个学员列显示其**当前有效目标**（学员覆盖优先，否则任务默认；未配置显示 `—`）；多任务时每个任务一行目标，整体作为表格首部。
2. **达标徽章**：最佳成绩（best-of）单元格旁显示该学员该任务是否达标（✅/✗）；判定遍历该学员该任务**全部轮次**，任一命中「满分且用时在区间」即达标；未配置区间不显示。
3. **概览汇总**：统计区增加达标人数 + 达标率（达标人数 / 参与人数）。
4. **学员覆盖**：学员旁"调整目标"入口，对该学员的某任务覆盖用时区间（写入 `training.studentGoals`）；未设置覆盖走任务默认区间。

## 涉及文件

- `public/inspire/training.html`（renderTrainingList 概览 + 覆盖弹窗）

## 验收要点

1. 概览**首行**为「🎯 目标」，各学员目标值正确（覆盖优先，未配置 `—`）。
2. 达标徽章正确；达标人数与达标率正确。
3. 学员覆盖后仅该学员按专属区间判定，刷新保留。
4. 无区间任务不显示徽章。
