# R4 · 集训达标展示

## 目标

在集训详情页把目标档位落地为可视化：达标徽章 + 当前目标 + 学员覆盖。**仅基于模拟赛/正赛（mockCompetitions）成绩**，自主练习不进入集训统计与排名。

## 交互

1. **当前目标**：每个学员的最佳成绩单元格内，在最佳值**下方**显示其「🎯 当前目标」——取目标档位中**下一档更快目标**（满分成绩 best 75s → 当前目标 70s；无满分成绩 → 最松档；全部达成 → 显示「已达全部目标」；未配置 `—`）。
2. **达标徽章**：最佳成绩（best-of）单元格旁显示该学员该任务当前目标是否达成（✅/✗）；判定基于满分成绩中最短用时 ≤ 当前目标档。
3. **学员覆盖**：学员旁"调整目标"入口，对该学员的某任务覆盖目标档位（写入 `training.studentGoals`）；未设置覆盖走任务默认档位。

## 涉及文件

- `public/inspire/training.html`（renderTrainingList 概览 + 覆盖弹窗）

## 验收要点

1. 每个学员最佳值**下方**显示「当前目标」，目标值正确（best 75→70，覆盖优先，未配置 `—`）。
2. 达标徽章正确。
3. 学员覆盖后仅该学员按专属档位判定，刷新保留。
4. 无档位任务不显示徽章/目标。
