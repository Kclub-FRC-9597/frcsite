# R5 · 个人数据展示

## 目标

在**个人成绩卡**（`student.js`）展示该学员的全部数据，提供自主练习 / 模拟练习的切换预览与达标展示。

## 交互

1. **全部数据**：个人成绩卡展示 模拟赛 + 正赛 + 自主练习 全部记录。
2. **分开/整合切换**：提供「自主练习 / 模拟练习」两种视图的**分开或整合**切换预览；模拟练习 = 模拟赛 + 正赛。
3. **达标与当前目标**：每任务最佳成绩下方显示「🎯 当前目标」（下一档更快目标，best 75s→70s）；达标徽章（✅/✗，满分成绩最短用时 ≤ 当前目标档）；未达标显示差距（还差几秒 / 未满分）；无档位任务显示「未设目标」。判定基于所选来源，默认模拟赛/正赛。

## 涉及文件

- `public/inspire/student.js`（个人成绩卡）

## 验收要点

1. 个人成绩卡展示全部数据，可切换 自主练习 / 模拟练习 分开或整合预览。
2. 每任务达标与「当前目标」正确（含学员覆盖），未达标显示差距。
3. 无档位任务显示「未设目标」。

## 不做

- 统计页（`stats.html`）暂不做目标/达标展示（后续按需）。
- 自主练习不进入集训统计与排名（见总纲「数据边界」）。
