# R3 · 任务梯度配置

## 目标

在**任务管理页**（`tasks.html`）提供梯度档位的创建/编辑入口，创建任务时设定、后续可改，全员共用。

## 交互

- 任务表单新增「🎯 目标梯度」区：
  - 档位列表（每档：名称 / 最低得分 / 最迟用时）
  - 「+ 添加档位」「删除」按钮
  - 阈值输入可留空（留空表示只看另一边）
- 保存任务时把档位写入 `task.goalLevels`。
- 未配置 = 空数组 = 该任务不参与判定。

## 涉及文件

- `public/inspire/tasks.html`（表单 + 保存逻辑）

## 验收要点

1. 增删档位、改名称/阈值正常，保存后刷新保留。
2. 新任务无梯度时保存为空数组，不影响其它功能。
