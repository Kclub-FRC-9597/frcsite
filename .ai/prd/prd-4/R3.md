# R3 · 任务目标配置

## 目标

在**任务管理页**（`tasks.html`）提供「目标时间档位」的配置入口，创建任务时统一设定、后续可改，全员共用。

## 交互

- 任务表单新增「🎯 目标档位」区：
  - 时间档位列表（秒），如 100 / 80 / 70，从松到紧
  - 「+ 添加档位」「删除」按钮
  - 说明文案：达成 = 学员满分且用时 ≤ 该档；当前目标 = 下一档更快目标
- 保存任务时写入 `task.goalTimes`。
- 未配置 = 该任务不参与目标判定。

## 涉及文件

- `public/inspire/tasks.html`（表单 + 保存逻辑）

## 验收要点

1. 增删/修改目标档位正常，保存后刷新保留。
2. 新任务未配置时无 `goalTimes`，不影响其它功能。
