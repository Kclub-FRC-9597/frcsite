# R2 · 满分用时判定

## 目标

定义任务「目标时间档位」的**数据模型**与**判定函数**，作为 R3/R4/R5 的公共基础。

## 数据模型

```js
// task 上：目标时间档位列表（从松到紧，越低越难；达成需 满分 + 用时 ≤ 档位）
task.goalTimes = [100, 80, 70]   // 秒；创建任务时统一设定，可后续调整
// 集训上：学员覆盖（可选）
training.studentGoals = [ { id, studentId, taskId, goalTimes: [/* 学员专属档位 */] } ]
```

- 未配置 `goalTimes` / 空数组 = 该任务不参与目标判定。
- **学员覆盖**（`training.studentGoals`）：用于首次训练绘制个人基准线——老师可为个别学员单独设档位（如新学员放宽、冲高收紧）；未设置覆盖的学员走任务默认档位。

## 判定规则

```
isGoalAchieved(bestFullScoreTime, goalTime):
    return bestFullScoreTime != null && bestFullScoreTime <= goalTime

currentGoal(bestFullScoreTime, goalTimes):
    if bestFullScoreTime == null: return max(goalTimes)          // 尚无满分成绩 → 目标=最松档
    next = max([t for t in goalTimes if t < bestFullScoreTime])  // 下一档更快目标
    return next ?? null                                          // null = 全部达成
```

- `bestFullScoreTime` = 该学员该任务**满分成绩中的最短用时**（满分前提）；无满分成绩为 null。
- 例：best 75s，goalTimes=[100,80,70] → 已达成 100、80 → 当前目标 **70s**。

> 满分取 `task.maxScore`；旧任务缺失该字段时，实施按「该任务历史最高得分」兜底为满分（R2 实施时确认）。

## 涉及文件

- `public/inspire/shared.js`：`Shared.getGoalTimes(task, training, studentId)`（解析学员覆盖）；`Shared.isGoalAchieved(bestFullScoreTime, goalTime)`；`Shared.currentGoal(bestFullScoreTime, goalTimes)`

## 验收要点

1. 判定函数行为与伪代码一致，单测覆盖：满分且达成某档、满分但未达档、非满分不算、无配置不参与、全部达成返回 null。
2. 旧任务无 `goalTimes` 时各统计不受影响。
