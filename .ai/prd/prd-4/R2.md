# R2 · 满分用时判定

## 目标

定义任务「满分前提下的用时区间」的**数据模型**与**判定函数**，作为 R3/R4/R5 的公共基础。

## 数据模型

```js
// task 上：满分前提下的用时区间（一个区间，无需命名）
task.goalTimeRange = {
  minTime: null,  // 用时下限（秒，可选，通常留空）
  maxTime: 12     // 用时上限（秒）
}
// 集训上：学员覆盖（可选）
training.studentGoals = [ { id, studentId, taskId, goalTimeRange: { minTime, maxTime } } ]
```

- `maxTime` 必填；`minTime` 可空（视为 0）。
- 未配置 `goalTimeRange` = 该任务不参与达标判定。
- **学员覆盖**（`training.studentGoals`）：用于首次训练绘制个人基准线——老师可为个别学员单独设用时区间（如新学员放宽、冲高收紧）；未设置覆盖的学员走任务默认区间。

## 判定规则

```
achieved(score, time, task, training, studentId):
    range = getGoalRange(task, training, studentId)   // 学员覆盖优先，否则任务默认
    if range == null: return null                     // 未配置 → 不参与
    if score != task.maxScore: return false           // 非满分不算达标
    low  = range.minTime ?? 0
    high = range.maxTime
    return time != null && low <= time && time <= high
```

成绩输入：学员**任意一次成绩**（满足满分且用时在区间即达标，无需 best-of）。

## 涉及文件

- `public/inspire/shared.js`：`Shared.getGoalRange(task, training, studentId)`（解析学员覆盖，R4 用）；`Shared.evaluateTimeGoal(score, time, task, training, studentId)`（判定是否达标）

## 验收要点

1. 判定函数行为与伪代码一致，单测覆盖：满分且在区间内达标、满分但超时未达标、非满分不算、未配置区间不参与。
2. 旧任务无 `goalTimeRange` 时各统计不受影响。
