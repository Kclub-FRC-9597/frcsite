# R2 · 梯度模型判定

## 目标

定义任务级梯度的**数据模型**与**判定函数**，作为 R3/R4/R5 的公共基础。

## 数据模型

```js
// task 上：梯度档位（自由增删）
task.goalLevels = [
  { id: 'lv1', name: '达标', minScore: 60, maxTime: 12 },
  { id: 'lv2', name: '良好', minScore: 80, maxTime: 10 },
  { id: 'lv3', name: '优秀', minScore: 90, maxTime: 8  }
]
```

- `minScore` 可空（只看用时）；`maxTime` 可空（只看得分）；两者都空则该档恒不满足（视为无效档）。
- 未配置 `goalLevels` / 空数组 = 该任务不参与等级判定。

## 判定规则

```
grade(bestScore, bestTime, levels):
    reached = null
    for lv in levels(按阈值升序):
        okScore = lv.minScore==null || bestScore>=lv.minScore
        okTime  = lv.maxTime==null || bestTime!=null && bestTime<=lv.maxTime
        if okScore && okTime: reached = lv
    return reached   // null = 未达标
```

成绩输入：学员**最佳成绩**（best-of：得分优先、同分取短用时），与现有概览口径一致。

## 涉及文件

- `public/inspire/shared.js`：`Shared.evaluateGoal(bestScore, bestTime, levels)`；`Shared.getGoalLevels(task, training, studentId)`（解析学员覆盖，R4 用）
- `public/inspire/analysis.js`：可选，把 best-of 取数复用给判定

## 验收要点

1. 判定函数行为与伪代码一致，单测覆盖：达标最高档、单边留空、无成绩/未达标、并列档位取最高。
2. 旧任务无 `goalLevels` 时各统计不受影响。
