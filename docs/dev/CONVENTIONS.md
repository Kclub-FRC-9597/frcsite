# Conventions

## Language

- TypeScript strict mode
- ESM imports

## Code Style

- See `.editorconfig` and `.prettierrc`
- API routes: one file per domain in `src/routes/`
- Frontend JS: vanilla, no framework dependency

## Commit Messages

Follow [Conventional Commits](https://www.conventionalcommits.org/)

## Documentation

- Project README: `README.md`
- Agent instructions: `AGENTS.md`
- Dev docs: `docs/dev/`
